# Career System

**Subtitle:** From Skills to Sustainable Professional Growth  
**Author:** Teresia Mrema Buza | Complex Data Insights

This scaffold starts the CDI Career System guide.

## Purpose

The Career System helps learners and professionals move from skill-building to sustainable professional growth.

It connects:

- career direction,
- skills inventory,
- learning plans,
- portfolio evidence,
- communication,
- mentorship,
- job readiness,
- workplace performance,
- resilience,
- and long-term growth.

## Initial files

- `_quarto.yml` — book configuration and full proposed chapter structure
- `index.qmd` — front page only, using the standard CDI cover format
- `00-preface.qmd` — opening chapter
- `01-system-overview.qmd` — system architecture and conceptual model

## Suggested setup

Create the project folder, then place these files at the root:

```bash
mkdir career-system
cd career-system
mkdir -p assets/images/cover
```

Place the cover image here:

```text
assets/images/cover/career-system-cover.png
```

Render the guide:

```bash
quarto render
```

Preview locally:

```bash
quarto preview
```
